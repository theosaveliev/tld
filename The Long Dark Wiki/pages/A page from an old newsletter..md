## Transcript

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **A page from an old newsletter.**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

Dear Civilian Corps members.

As discussed at our last meeting, we're pleased with how many volunteers have stepped up to host a radio for our new emergency network plan. As of tomorrow, we'll have civilian broadcast capability from nearly every community on Great Bear. We're confident this will give us good coverage for enabling two-way emergency transmission from the coast all the way to the Far Territory.

If you're near one of these locations, and would like to volunteer for a shift monitoring the radios, please see the Corps officer in your locale about signing up.

With tremors increasing, building a durable radio network could make all the difference when the big one hits.

With gratitude,

Jen Whitney, Executive Officer
