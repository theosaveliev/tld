**Basement Key** is a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> item found in <a href="./Episode%203%20-%20Crossroads%20Elegy.md" class="wikilink" title="Episode 3">Episode 3</a> of the <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> story mode as a part of the <a href="./Trauma.md" class="wikilink" title="Trauma">Trauma</a> mission.

During the course of the mission, Astrid finds the key within the Flower <a href="./Vase.md" class="wikilink" title="Vase">Vase</a> within the <a href="./Pleasant%20Valley%20Farmstead.md" class="wikilink" title="Pleasant Valley Farmstead">Pleasant Valley Farmstead</a>. The key unlocks the basement that contains medical supplies, a <a href="./Revolver.md" class="wikilink" title="Revolver">Revolver</a>, <a href="./Rifle%20Ammunition.md" class="wikilink" title="Rifle Ammunition">Rifle Ammunition</a>, and an unlocked exit to the house.
