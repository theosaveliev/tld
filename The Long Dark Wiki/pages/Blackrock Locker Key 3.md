**Blackrock Locker Key \#3** is a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> note found in <a href="./Episode%204%20-%20Fury%2C%20Then%20Silence.md" class="wikilink" title="Episode 4">Episode 4</a> of the <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> story as part of the side mission <a href="./Blackrock%20Lockers.md" class="wikilink" title="Blackrock Lockers">Blackrock Lockers</a>. It is found in the <a href="./Glove%20Box.md" class="wikilink" title="Glove Box">Glove Box</a> of the <a href="./Truck.md" class="wikilink" title="Truck">Truck</a> in the barn near <a href="./Jailer%27s%20Residence.md" class="wikilink" title="Jailer&#39;s Residence">Jailer's Residence</a>. It is used to open Locker \#3 which contains 5 <a href="./Rifle%20Ammunition.md" class="wikilink" title="Rifle Ammunition">Rifle Ammunition</a>, a <a href="./Hunting%20Knife.md" class="wikilink" title="Hunting Knife">Hunting Knife</a>, an <a href="./Emergency%20Stim.md" class="wikilink" title="Emergency Stim">Emergency Stim</a>, and a <a href="./Archival%20Report.md" class="wikilink" title="Archival Report">Archival Report</a>.
