Broken Body is a permanent Affliction unique to <a href="./Misery.md" class="wikilink" title="Misery Mode">Misery Mode</a> which occurs from Stage 5 of Misery (Day 47). It completely disables Condition recovery and doubles all sources of Condition drain.

## Effects

- All forms of <a href="./Condition.md" class="wikilink" title="Condition">Condition</a> recovery are disabled (Passive from met <a href="./Needs.md" class="wikilink" title="Needs">Needs</a>, <a href="./Sleep.md" class="wikilink" title="Sleep">Sleep</a> and all <a href="./Emergency%20Stim.md" class="wikilink" title="Items">Items</a>)
- +100% Condition damage taken

## Trivia

- All negative condition drains are affected. This includes negative afflictions, falling into <a href="./Weak%20Ice.md" class="wikilink" title="weak ice">weak ice</a>, fall damage, starvation, contact with <a href="./Burns.md" class="wikilink" title="fire hazards">fire hazards</a> (electricity and flames), and so on.
- Despite doubling all negative sources that drain Condition, Broken Body does not affect the final damage dealt by post-<a href="./Struggle.md" class="wikilink" title="struggle">struggle</a> attacks from <a href="./Bear.md" class="wikilink" title="Bears">Bears</a>, <a href="./Moose.md" class="wikilink" title="Moose">Moose</a>, and <a href="./Cougar.md" class="wikilink" title="Cougars">Cougars</a>. The only exception is <a href="./Wolf.md" class="wikilink" title="wolves">wolves</a>.
  - This means that if the player is ever attacked by any of these creatures, having 100% protection will not result in an instant game over.
- Has synergy with the Misery affliction "<a href="./Rheumatic%20Joints.md" class="wikilink" title="Rheumatic Joints&quot;">Rheumatic Joints"</a>, which causes 4% Condition loss when receiving a <a href="./Sprained%20Ankle.md" class="wikilink" title="Sprain">Sprain</a>.
- Has synergy with the Misery affliction "<a href="./Sour%20Stomach.md" class="wikilink" title="Sour Stomach">Sour Stomach</a>", which disables the benefit from <a href="./Cooking.md" class="wikilink" title="Cooking Skill">Cooking Skill</a> level 5 preventing <a href="./Food%20Poisoning.md" class="wikilink" title="Food Poisoning">Food Poisoning</a> risk when eating cooked or <a href="./Tin%20of%20Sardines.md" class="wikilink" title="artificial food">artificial food</a>.
- Has synergy with the Misery affliction "<a href="./Frigid%20Bones.md" class="wikilink" title="Frigid Bones">Frigid Bones</a>", which reduces the survivor's <a href="./Feels%20Like.md" class="wikilink" title="Feels Like">Feels Like</a> temperature and the rate which <a href="./Warmth.md" class="wikilink" title="Warmth">Warmth</a> refills.
- Has negative synergy with the Misery affliction "<a href="./Haunted%20Mind.md" class="wikilink" title="Haunted Mind">Haunted Mind</a>", which reduces Condition recovery from <a href="./Sleep.md" class="wikilink" title="Sleep">Sleep</a> by 50%, while Broken Body disables all forms of Condition recovery completely.
