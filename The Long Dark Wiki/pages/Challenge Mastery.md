**Challenge Mastery** is an <a href="./The%20Long%20Dark%20%E2%80%94%20Achievements.md" class="wikilink" title="achievement">achievement</a> in *<a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>*.

## Guide

This achievement is obtained after successfully completing every <a href="./Challenge.md" class="wikilink" title="Challenge">Challenge</a>, with the exception of <a href="./As%20the%20Dead%20Sleep.md" class="wikilink" title="As the Dead Sleep">As the Dead Sleep</a> and <a href="./Escape%20the%20Darkwalker.md" class="wikilink" title="Escape the Darkwalker">Escape the Darkwalker</a>. This achievement is one of the more challenging ones to get, as some challenges are easier to complete than others, especially for players who don't know Great Bear Island very well and are newer to the game.

### Challenges

- <a href="./Nomad.md" class="wikilink" title="Nomad">Nomad</a>: Generally the easiest challenge for new players. Good tour of Great Bear for those who are not familiar.
- <a href="./Archivist.md" class="wikilink" title="Archivist">Archivist</a>: Also quite easy, though travel at night during the <a href="./Aurora.md" class="wikilink" title="Aurora">Aurora</a> can be hazardous due to aggressive predators.
- <a href="./Whiteout.md" class="wikilink" title="Whiteout">Whiteout</a>: Usually not too difficult, however this depends on RNG. Most supplies can be found in <a href="./Coastal%20Highway.md" class="wikilink" title="Coastal Highway">Coastal Highway</a>, though sometimes a trip to <a href="./Pleasant%20Valley.md" class="wikilink" title="Pleasant Valley">Pleasant Valley</a> or <a href="./Desolation%20Point.md" class="wikilink" title="Desolation Point">Desolation Point</a> is necessary.
- <a href="./Hopeless%20Rescue.md" class="wikilink" title="Hopeless Rescue">Hopeless Rescue</a>: Easy for players who know their way around <a href="./Mystery%20Lake%20%28region%29.md" class="wikilink" title="Mystery Lake">Mystery Lake</a>, <a href="./Pleasant%20Valley.md" class="wikilink" title="Pleasant Valley">Pleasant Valley</a>, <a href="./Timberwolf%20Mountain.md" class="wikilink" title="Timberwolf Mountain">Timberwolf Mountain</a>, <a href="./Coastal%20Highway.md" class="wikilink" title="Coastal Highway">Coastal Highway</a>, and <a href="./Desolation%20Point.md" class="wikilink" title="Desolation Point">Desolation Point</a>. If not, it is very difficult. <a href="./Tin%20of%20Coffee.md" class="wikilink" title="Coffee">Coffee</a> can make this challenge much easier.
- <a href="./The%20Hunted%2C%20Part%20One.md" class="wikilink" title="The Hunted, Part One">The Hunted, Part One</a>: The <a href="./Old%20Bear.md" class="wikilink" title="Old Bear">Old Bear</a> is aggressive but can be scared off the same way as <a href="./Wolf.md" class="wikilink" title="wolves">wolves</a>. Keeping a good supply of <a href="./Torch.md" class="wikilink" title="torches">torches</a> and knowing <a href="./Pleasant%20Valley.md" class="wikilink" title="Pleasant Valley">Pleasant Valley</a> and <a href="./Mystery%20Lake%20%28region%29.md" class="wikilink" title="Mystery Lake">Mystery Lake</a> makes this much easier.
- <a href="./The%20Hunted%2C%20Part%20Two.md" class="wikilink" title="The Hunted, Part Two">The Hunted, Part Two</a>: As long as the player uses torches and flares to scare off wolves, there should be enough bullets to deal with the bear. Not too difficult.
