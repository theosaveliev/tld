**Cured Rabbit Pelt** is the cured hide of a <a href="./Fresh%20Rabbit%20Pelt.md" class="wikilink" title="Fresh Rabbit Pelt">Fresh Rabbit Pelt</a>. It can be used as a <a href="./Materials.md" class="wikilink" title="Material">Material</a> for crafting or repairing <a href="./Rabbitskin%20Mitts.md" class="wikilink" title="Rabbitskin Mitts">Rabbitskin Mitts</a> and <a href="./Rabbitskin%20Hat.md" class="wikilink" title="Rabbitskin Hats">Rabbitskin Hats</a>.

## Overview

Fresh Rabbit Pelt are acquired by harvesting a <a href="./Rabbit%20Carcass.md" class="wikilink" title="Rabbit Carcass">Rabbit Carcass</a>, they can then be cured by leaving them indoors for 3 days (in-game). Cured Rabbit Pelts are used for crafting or repairing <a href="./Rabbitskin%20Hat.md" class="wikilink" title="Rabbitskin Hat">Rabbitskin Hats</a> and <a href="./Rabbitskin%20Mitts.md" class="wikilink" title="Rabbitskin Mitts">Rabbitskin Mitts</a>. Once cured, the hide will take on a darker complexion, and can then be used for crafting.

Rabbit Pelts are acquired by <a href="./Trapping.md" class="wikilink" title="Trapping">Trapping</a>, stunning rabbits with a <a href="./Stone.md" class="wikilink" title="Stone">Stone</a>, or shooting a rabbit. Each Rabbit Carcass will have one pelt, along with <a href="./Rabbit%20%28Raw%29.md" class="wikilink" title="meat">meat</a> and <a href="./Fresh%20Gut.md" class="wikilink" title="Fresh Gut">Fresh Gut</a>.

Cured Rabbit Pelts are widely used for <a href="./Trader.md" class="wikilink" title="trading">trading</a>, as they are the fastest hide to cure and can easily be obtained in large quantities. They can be used to purchase <a href="./Rifle%20Ammunition.md" class="wikilink" title="Rifle Ammunition">Rifle Ammunition</a>, <a href="./Revolver%20Ammunition.md" class="wikilink" title="Revolver Ammunition">Revolver Ammunition</a>, <a href="./Flare%20Shell.md" class="wikilink" title="flare shells">flare shells</a>, an <a href="./Aviator%20Cap.md" class="wikilink" title="Aviator Cap">Aviator Cap</a>, <a href="./Thin%20Wool%20Sweater.md" class="wikilink" title="Thin Wool Sweater">Thin Wool Sweater</a>, <a href="./Wool%20Shirt.md" class="wikilink" title="Wool Shirt">Wool Shirt</a>, <a href="./Thick%20Wool%20Sweater.md" class="wikilink" title="Thick Wool Sweater">Thick Wool Sweater</a>, <a href="./Light%20Shell.md" class="wikilink" title="Light Shell">Light Shell</a>, <a href="./Mackinaw%20Jacket.md" class="wikilink" title="Mackinaw Jacket">Mackinaw Jacket</a>, <a href="./Mukluks.md" class="wikilink" title="Mukluks">Mukluks</a>, <a href="./Manufactured%20Arrow.md" class="wikilink" title="Manufactured Arrow">Manufactured Arrow</a>, the <a href="./Bushcraft%20Bow%20Blueprint%20Card.md" class="wikilink" title="Bushcraft Bow Blueprint Card">Bushcraft Bow Blueprint Card</a>, as well as <a href="./T-Shirt%20%28CM%29.md" class="wikilink" title="three">three</a> <a href="./T-Shirt%20%28GBI%29.md" class="wikilink" title="different">different</a> <a href="./T-Shirt%20%28Snappy%29.md" class="wikilink" title="T-Shirts">T-Shirts</a> and <a href="./Patterned%20Wool%20Socks%20%28Dots%29.md" class="wikilink" title="three">three</a> <a href="./Patterned%20Wool%20Socks%20%28Moose%29.md" class="wikilink" title="different">different</a> <a href="./Patterned%20Wool%20Socks%20%28Plaid%29.md" class="wikilink" title="wool socks">wool socks</a>.
