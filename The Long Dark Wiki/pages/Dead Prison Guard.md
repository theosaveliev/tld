A **Dead Prison Guard** is a uniquely named <a href="./Frozen%20Corpse.md" class="wikilink" title="Frozen Corpse">Frozen Corpse</a> found in <a href="./Episode%203%20-%20Crossroads%20Elegy.md" class="wikilink" title="Episode 3: Crossroads Elegy">Episode 3: Crossroads Elegy</a>. He belonged to the <a href="./Crashed%20Prison%20Transport%20Bus.md" class="wikilink" title="Crashed Prison Transport Bus">Crashed Prison Transport Bus</a> after the <a href="./First%20Flare.md" class="wikilink" title="First Flare">First Flare</a> caused some of the inmates to scatter into <a href="./Pleasant%20Valley.md" class="wikilink" title="Pleasant Valley">Pleasant Valley</a>. He holds the <a href="./Blackrock%20Penitentiary%20Memo.md" class="wikilink" title="Blackrock Penitentiary Memo">Blackrock Penitentiary Memo</a>, but otherwise functions as a normal Frozen Corpse and has the same storage capacity as any other corpse.

A Dead Prison Guard is found in <a href="./Episode%204%20-%20Fury%2C%20Then%20Silence.md" class="wikilink" title="Episode 4: Fury, then Silence">Episode 4: Fury, then Silence</a> as part of the <a href="./Blackrock%20Blues.md" class="wikilink" title="Blackrock Blues">Blackrock Blues</a> mission next to a <a href="./First%20Aid%20Kit.md" class="wikilink" title="First Aid Kit">First Aid Kit</a> containing the <a href="./Blackrock%20Infirmary%20Medication.md" class="wikilink" title="Blackrock Infirmary Medication">Blackrock Infirmary Medication</a>.

Another Dead Prisoner Guard can be found as part of the side mission <a href="./Blackrock%20Rumours.md" class="wikilink" title="Blackrock Rumours">Blackrock Rumours</a> - Missing Employee as a dead man named Murphy. He was panning for gold, and can be found in a ravine with the <a href="./Lock%20Box%20Key.md" class="wikilink" title="Lock Box Key">Lock Box Key</a> and <a href="./Notebook%20Page.md" class="wikilink" title="Notebook Page">Notebook Page</a> items. His lockbox key opens a lockbox containing a <a href="./Gold%20Nugget.md" class="wikilink" title="Gold Nugget">Gold Nugget</a>.
