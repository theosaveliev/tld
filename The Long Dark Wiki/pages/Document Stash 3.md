<p><strong>Document Stash 3</strong> is an item found during <a href="./Sutherland%27s%20Tale.md" class="wikilink" title="Sutherland&#39;s Tale">Sutherland's Tale</a>.</p>
<h2 id="Overview">Overview</h2>
<p>It is found in a <a href="./Loose%20Bricks%20Stash.md" class="wikilink" title="Loose Bricks Stash">Loose Bricks Stash</a> in the Conspiracy <a href="./Prepper%20Cache.md" class="wikilink" title="Prepper Cache">Prepper Cache</a> and contains <a href="./Wyatt%27s%20Lost%20Papers%203.md" class="wikilink" title="Wyatt&#39;s Lost Papers 3">Wyatt's Lost Papers 3</a> and <a href="./Bunker%20Schematic%20Fragment%203.md" class="wikilink" title="Bunker Schematic Fragment 3">Bunker Schematic Fragment 3</a>. It must be placed in the <a href="./Trade%20Drop%20Box.md" class="wikilink" title="Trade Drop Box">Trade Drop Box</a> as the 3rd Special Request to Sutherland to advance his questline.</p>
<p>It cannot be dropped or placed in a container, so it cannot be lost.</p>
