**Emergency Kit Note** was a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> item found in <a href="./Episode%201%20-%20Do%20Not%20Go%20Gentle.md" class="wikilink" title="Episode 1: Do Not Go Gentle">Episode 1: Do Not Go Gentle</a> of the <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> story mode in <a href="./Paradise%20Meadows%20Farm.md" class="wikilink" title="Paradise Meadows Farm">Paradise Meadows Farm</a>. It is considered <a href="./Cut%20%E2%80%94%20Discontinued%20Content.md" class="wikilink" title="Cut/Discontinued Content">Cut/Discontinued Content</a>, as it did not survive the transition from Predux Episode 1 to Redux Episode 1, as the Lockbox and <a href="./Lock%20Box%20Key%20%28Predux%29.md" class="wikilink" title="Lock Box Key (Predux)">Lock Box Key (Predux)</a> needed to open it was removed from the game and replaced with a different Lockbox that <a href="./Hobbs.md" class="wikilink" title="Hobbs">Hobbs</a> finds.
