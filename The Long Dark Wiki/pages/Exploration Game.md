**Exploration Game** is an <a href="./The%20Long%20Dark%20%E2%80%94%20Achievements.md" class="wikilink" title="achievement">achievement</a> in *<a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>*.

## Guide

This achievement is obtained after entering every interior location in <a href="./Mystery%20Lake%20%28region%29.md" class="wikilink" title="Mystery Lake">Mystery Lake</a> and <a href="./Coastal%20Highway.md" class="wikilink" title="Coastal Highway">Coastal Highway</a> in a single <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> game. It is most easily done on <a href="./Pilgrim.md" class="wikilink" title="Pilgrim">Pilgrim</a>.

Interior locations include buildings and other structures that have a loading screen when entering them. This excludes <a href="./Fishing%20Hut.md" class="wikilink" title="Fishing Huts">Fishing Huts</a>, <a href="./Car.md" class="wikilink" title="Car">Cars</a>, and <a href="./Abandoned%20Lookout.md" class="wikilink" title="Abandoned Lookout">Abandoned Lookout</a>. The exceptions are the <a href="./Forestry%20Lookout.md" class="wikilink" title="Forestry Lookout">Forestry Lookout</a>, which does not have a loading screen but is included.
