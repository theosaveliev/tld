**Faded Paper** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Episode%205%20-%20The%20Light%20At%20The%20End%20Of%20All%20Things.md" class="wikilink" title="Episode 5">Episode 5</a> of the <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> story. It is found during the main mission <a href="./High%20Energy.md" class="wikilink" title="High Energy">High Energy</a>, pinned to a chalkboard inside the <a href="./Suzuki%20Radio%20Telescope.md" class="wikilink" title="Suzuki Radio Telescope">Suzuki Radio Telescope</a>, in a large room with 3 terminals before reaching <a href="./Atwood.md" class="wikilink" title="Atwood&#39;s">Atwood's</a> office.

## Transcript

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **Faded Paper**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

Excavation Log\
Day 74

The blasting crew had to stop work again today. It's slow progress, but they tell me the density of the rock is unlike anything they've seen before.

Brittle in places, but diamond=hard in others. I'm no engineer, but it's creating some unique challenges for keeping us on time and under budget,

We know the required depth the scientists demanded we hit, but they won't tell us why.

"Compartmentalization," they call it. I'm sure some government lawyer invented that word just for guys like me.

In any case we push on. The team arrives next week to see how effective the shielding will be. Physicists from back east some where.

Their verdict seems to carry all the weight of this project.

We will see.

K.Rice\
Project Manager
