**Fisherman's Sweater** is a type of <a href="./Clothing.md" class="wikilink" title="clothing">clothing</a> in *<a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>*.

## Overview

The Fisherman's Sweater is a thick, heavy clothing item with a nautical fashion style. It is quite warm but rare, and has one of the best weight-to-warmth ratio of all sweaters, with warmth similar (but slightly inferior to) the rare <a href="./Cowichan%20Sweater.md" class="wikilink" title="Cowichan Sweater">Cowichan Sweater</a>, while weighing half as much. It is a direct upgrade to the <a href="./Thick%20Wool%20Sweater.md" class="wikilink" title="Thick Wool Sweater">Thick Wool Sweater</a>, with better stats while weighing the same. It also looks like an [Aran-Knit Sweater](https://en.wikipedia.org/wiki/Aran_jumper).

A set of Fisherman Sweater's is guaranteed from <a href="./Timberwolf%20Mountain.md" class="wikilink" title="Timberwolf Mountain">Timberwolf Mountain</a> at the <a href="./Summit.md" class="wikilink" title="Summit">Summit</a> and inside a <a href="./Mementos.md" class="wikilink" title="Memento">Memento</a> Cache in <a href="./Bleak%20Inlet.md" class="wikilink" title="Bleak Inlet">Bleak Inlet</a>.

Fisherman's Sweater is not available on <a href="./Interloper.md" class="wikilink" title="Interloper">Interloper</a> mode.
