**Foreman's Site Report Day 64** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> as part of the <a href="./Buried%20Echoes.md" class="wikilink" title="Buried Echoes">Buried Echoes</a> <a href="./Tales.md" class="wikilink" title="Tale">Tale</a>. It is found when descending down the mineshaft on a <a href="./Supply%20Bin.md" class="wikilink" title="Supply Bin">Supply Bin</a> inside the locked mountainside section of the <a href="./Langston%20Mine.md" class="wikilink" title="Langston Mine">Langston Mine</a>.
