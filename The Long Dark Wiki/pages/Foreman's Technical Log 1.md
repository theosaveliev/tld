**Foreman's Technical Log 1** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> as part of the <a href="./Last%20Horizon.md" class="wikilink" title="Last Horizon">Last Horizon</a> <a href="./Tales.md" class="wikilink" title="Tale">Tale</a>. It is found buried in a <a href="./Lock%20Box.md" class="wikilink" title="Lock Box">Lock Box</a> at the <a href="./Weather%20Station.md" class="wikilink" title="Weather Station">Weather Station</a> in <a href="./Sundered%20Pass.md" class="wikilink" title="Sundered Pass">Sundered Pass</a>.

## Transcript

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **Foreman's Technical Log 1**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

\[clear, deliberate handwriting...\]

I think I'm the only one who made it out. The other guys...just lost it. Started wandering off. I'm not immune to whatever happened. It just didn't hit me as bad as the others. The Chief either. I don't know why.

She held out a long time. A damn long time. But the she just locked herself in there with that blasted machine.

She died before she could learn the truth about my real mission here.

</div>
