**Foreman's Technical Log 2** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> as part of the <a href="./Last%20Horizon.md" class="wikilink" title="Last Horizon">Last Horizon</a> <a href="./Tales.md" class="wikilink" title="Tale">Tale</a>. It is found in the locked room of <a href="./Last%20Lonely%20House.md" class="wikilink" title="Last Lonely House">Last Lonely House</a> in <a href="./Sundered%20Pass.md" class="wikilink" title="Sundered Pass">Sundered Pass</a>.

## Transcript

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **Foreman's Technical Log 2**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

\[lazy handwriting, with some passages scratched out...\]

Rüdiger’s here somewhere – the Chief’s logbook said as much. I’ll keep looking. There’s a settlement nearby I need to check out.

I’m gonna try and keep a record of all this, as long as I’m able. Photos, whatever I can. These notes. If I make it back I’ll need something to show for how this all went to shit.

\*They\* will want to know.

But I keep losing things, leaving them behind…can’t hold it together.

</div>
