**Foreman's Technical Log 3** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> as part of the <a href="./Last%20Horizon.md" class="wikilink" title="Last Horizon">Last Horizon</a> <a href="./Tales.md" class="wikilink" title="Tale">Tale</a>. It is found at the <a href="./High%20Peak%20Plateau.md" class="wikilink" title="High Peak Plateau">High Peak Plateau</a> in <a href="./Sundered%20Pass.md" class="wikilink" title="Sundered Pass">Sundered Pass</a> while following the Tale.

## Transcript

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **Foreman's Technical Log 3**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

\[paper fragment with shaky handwriting...\]

Tracked the slippery creep up here, but he's moving fast. Stronger than he looks, and just as I'm starting to fade.

I knew this might be a one-way trip, but I liked my odds for something better. One last mission to fill the ledger before moving on to better days. Debts paid, the director off my back for good.

Some bright idea, huh?

I miss my brother. He would have loved this op. Can't...really see his face anymore.

Feel bad for the guys that didn't get out. That \*goddamn\* mine. Part of the gig to keep them in the dark, but this one hurt.

Well then.

It's almost kinda nice when the sun's up. And the wind stops howling.

Onward. Gotta fix this. Finish it.

</div>
