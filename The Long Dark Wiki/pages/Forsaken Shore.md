**Forsaken Shore** is the 3rd <a href="./The%20Long%20Development.md" class="wikilink" title="Modded Region">Modded Region</a> added to the game, as part of The Long Development's unofficial region mods. The region connects from <a href="./Rocky%20Thoroughfare.md" class="wikilink" title="Rocky Thoroughfare">Rocky Thoroughfare</a>.

## Overview

The region features two areas: an area near the coast, and an inland half with significant elevation differences. There is a <a href="./Chemical%20Hazard.md" class="wikilink" title="Chemical Hazard">Chemical Hazard</a> present around one of islands just off the shore.

## Locations

There are a number of accessible locations in this region, including:

- Bisected Path
- Cliffside Cabin
- Coastal Community
- Derelict Oil Platform
- Despondent Crag (formerly a region, but merged into Forsaken Shore)
- Dom's Cave
- Fishing Lodge
- Kai's Hideout
- Loggers Residence
- Lower Pipeline
- Smoldered Respite
- Travelers Pass
- Upper Pipeline
- Upper Shelf

The region also has a beached fishing trawler, using the same model as The Harbinger near the <a href="./Last%20Resort%20Cannery.md" class="wikilink" title="Last Resort Cannery">Last Resort Cannery</a>, containing a <a href="./Cargo%20Container.md" class="wikilink" title="Cargo Container">Cargo Container</a> on board.
