**ID: Naomi Moore** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a>. It is currently unknown if it is associated with one of the <a href="./Tales.md" class="wikilink" title="Tales">Tales</a>, as it is in the game files but may be unused. It is currently considered <a href="./Cut%20%E2%80%94%20Discontinued%20Content.md" class="wikilink" title="Cut/Discontinued Content">Cut/Discontinued Content</a>.

It appears to be related to <a href="./Escape%20the%20Darkwalker.md" class="wikilink" title="Escape the Darkwalker">Escape the Darkwalker</a>, but it cannot be found (listed in game files as Darkwalker ID).
