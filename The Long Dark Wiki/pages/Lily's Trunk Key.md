**Lily's Trunk Key** is a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> item obtained as a reward in <a href="./Episode%201%20-%20Do%20Not%20Go%20Gentle.md" class="wikilink" title="Episode 1">Episode 1</a> of the <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> story mode for the <a href="./The%20Grey%20Mother.md" class="wikilink" title="The Grey Mother">The Grey Mother</a> mission.

The key unlocks a blue <a href="./Trunk.md" class="wikilink" title="Trunk">Trunk</a> upstairs in <a href="./Milton%20House%20%28Grey%20Mother%27s%29.md" class="wikilink" title="Milton House (Grey Mother&#39;s)">Milton House (Grey Mother's)</a> that contains <a href="./Mountaineering%20Rope.md" class="wikilink" title="Mountaineering Rope">Mountaineering Rope</a> and <a href="./Lily%27s%20Map.md" class="wikilink" title="Lily&#39;s Map">Lily's Map</a>, which are needed to start the mission <a href="./Paradise%20Lost.md" class="wikilink" title="Paradise Lost">Paradise Lost</a>.
