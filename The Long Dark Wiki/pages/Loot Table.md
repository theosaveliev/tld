The **loot table** is a gameplay mechanic in [Survival Mode](./Survival%20Mode.md) which determines where certain items spawn in a given sandbox (game).

Every Survival Mode sandbox belongs to one of four loot tables. There is a standard numbering to the four loot tables (numbered 1-4). If your game is on Loot Table 2, then it will be on Loot Table 2 across every region, and remain on Loot Table 2 even if you [Cheat Death](./Cheat%20Death.md).

The loot table system is active regardless of sandbox difficulty. It is common for [Interloper](./Interloper.md) and [Misery](./Misery.md) players to identify which loot table their game is on so that they can quickly find crucial loot. For example, finding a hammer in [Molly's Barn](./Barn%20%28Molly%27s%29.md) means that you are on Loot Table 1, which guarantees that you can find a [magnifying lens](./Magnifying%20Lens.md) in the [Pleasant Valley Farmstead](./Pleasant%20Valley%20Farmstead.md) basement and a [firestriker](./Firestriker.md) in [Abandoned Mine No. 5](./Abandoned%20Mine%20No.%205.md).

## What is and is not affected by loot tables

Loot tables determine the locations of these items:

- [Firestriker](./Firestriker.md)
- [Magnifying lens](./Magnifying%20Lens.md)
- [Lantern](./Lantern.md)
- [Spelunker's Lantern](./Spelunker%27s%20Lantern.md)
- [Bedroll](./Bedroll.md)
- [Heavy hammer](./Heavy%20Hammer.md)
- [Hacksaw](./Hacksaw.md)
- Some, but not all, [prybars](./Prybar.md)
- Vista [Polaroids](./Polaroids.md)
- [Supply Cache](./Supply%20Cache.md)

Loot tables do **not** appear to be linked to the locations of these items:

- [Wood Matches](./Wood%20Matches.md)
- [Cooking Pot](./Cooking%20Pot.md)
- [Cooking Skillet](./Cooking%20Skillet.md)
- [Emergency Stim](./Emergency%20Stim.md)
- [Jerry Can](./Jerry%20Can.md)
- High-value clothing
