The **loot table** is a gameplay mechanic in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> which determines where certain items spawn in a given sandbox (game).

Every Survival Mode sandbox belongs to one of four loot tables. There is a standard numbering to the four loot tables (numbered 1-4). If your game is on Loot Table 2, then it will be on Loot Table 2 across every region, and remain on Loot Table 2 even if you <a href="./Cheat%20Death.md" class="wikilink" title="Cheat Death">Cheat Death</a>.

The loot table system is active regardless of sandbox difficulty. It is common for <a href="./Interloper.md" class="wikilink" title="Interloper">Interloper</a> and <a href="./Misery.md" class="wikilink" title="Misery">Misery</a> players to identify which loot table their game is on so that they can quickly find crucial loot. For example, finding a hammer in <a href="./Barn%20%28Molly%27s%29.md" class="wikilink" title="Molly&#39;s Barn">Molly's Barn</a> means that you are on Loot Table 1, which guarantees that you can find a <a href="./Magnifying%20Lens.md" class="wikilink" title="magnifying lens">magnifying lens</a> in the <a href="./Pleasant%20Valley%20Farmstead.md" class="wikilink" title="Pleasant Valley Farmstead">Pleasant Valley Farmstead</a> basement and a <a href="./Firestriker.md" class="wikilink" title="firestriker">firestriker</a> in <a href="./Abandoned%20Mine%20No.%205.md" class="wikilink" title="Abandoned Mine No. 5">Abandoned Mine No. 5</a>.
