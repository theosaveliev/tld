**On the Nature of Darkwalkers** is a note found only in the <a href="./Challenge.md" class="wikilink" title="Challenge">Challenge</a> <a href="./Escape%20the%20Darkwalker.md" class="wikilink" title="Escape the Darkwalker">Escape the Darkwalker</a>.

This note is separate from the 10 notes, <a href="./Diary%20Page%20%28Darkwalker%29.md" class="wikilink" title="Diary Page (Darkwalker)">Diary Page (Darkwalker)</a>, found across the Challenge in different locations, and does not need to be collected to complete the Challenge.

## Transcript

### Starting Location

This note always appears beside the player in the region they first spawn in, next to the burned out Campfire.

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **On the Nature of Darkwalkers**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

Glyphs of Power and their Uses:

Lure -- Attract the Darkwalker\
Ward -- A shield, if only for a little while.\
Dispel -- Push back the choking fog. But only once.

Darkwalkers spread fear and feed on oblivion - knowledge will help you defeat the entity for good.

</div>
