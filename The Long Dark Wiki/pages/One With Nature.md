**One With Nature** was an <a href="./The%20Long%20Dark%20%E2%80%94%20Achievements.md" class="wikilink" title="achievement">achievement</a> in *<a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>*. At the release of <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> (v1.00), it was removed from the game and no longer displays in Steam, nor is it included in the console ports of the game.

## Guide

This achievement is obtained after surviving for 200 days in a single <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> game. It is most easily done on Pilgrim.**Lua execution error in Module:Navbox function navbox**
