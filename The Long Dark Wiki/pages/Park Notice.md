**Park Notice** is a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> item found in <a href="./Episode%202%20-%20Luminance%20Fugue.md" class="wikilink" title="Episode 2">Episode 2</a> of <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a>. It is found in the <a href="./Camp%20Office.md" class="wikilink" title="Camp Office">Camp Office</a> on the front counter.

## Transcript

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **Park Notice**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

"Due to unusually cold weather this year, we're shutting down Mystery Lake provincial park a little earlier than usual. Make sure all the campers are packed up and ready to bug out by rail-truck. Anyone left behind will have to get out on foot -- not a nice prospect. As per the usual procedure, lock up all lake cabins and make sure all provisions are stored in bear-proof containers. And please take the flag down this year -- we had to replace it after last Winter. The winds just tear it to shreds. After you're finished closing down the camp, make sure to check in at the Forestry Service Lookout as requested. Apparently those guys think <a href="./Jeremiah.md" class="wikilink" title="someone&#39;s">someone's</a> been using their lookout to store hunting gear, and drying old animal skins? Man, I don't envy you that backwater posting. Great Bear has sure gone downhill since the quakes."

</div>
