<td><p>Has an interior|} <strong>Platelayer's Shortcut</strong> is a moderately complex system of indoor caves in the <a href="./Far%20Range%20Branch%20Line.md" class="wikilink" title="Far Range Branch Line">Far Range Branch Line</a> area. It contains <a href="./Coal.md" class="wikilink" title="Coal">Coal</a> and <a href="./Stick.md" class="wikilink" title="sticks">sticks</a> as well as a few dead <a href="./Deer.md" class="wikilink" title="Deer">Deer</a> and possibly human corpses. It is used to navigate the rockfall blockage located at <a href="./Foundered%20Track.md" class="wikilink" title="Foundered Track">Foundered Track</a>.</p>
<p>The lower cave entrance is found below <a href="./Surfeit%20Trestle.md" class="wikilink" title="Surfeit Trestle">Surfeit Trestle</a>.
