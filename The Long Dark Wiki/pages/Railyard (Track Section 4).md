<h2 id="Overview">Overview</h2>
<h3 id="Railyard_East">Railyard East</h3>
<p>A mostly empty set of land with some tracks that lead into a smashed in tunnel leading to <a href="./Anna%20Island%20--%20Track%20Section%206.md" class="wikilink" title="Anna Island -- Track Section 6">Anna Island -- Track Section 6</a>. Further east leads to <a href="./Anna%20Island%20--%20Track%20Section%205.md" class="wikilink" title="Anna Island -- Track Section 5">Anna Island -- Track Section 5</a>.</p>
<h3 id="Railyard_West">Railyard West</h3>
<p>To the west of the map lies the first <a href="./Repair%20Depot.md" class="wikilink" title="Repair Depots">Repair Depots</a> the player will find after acquiring the <a href="./Prototype%20Train.md" class="wikilink" title="Prototype Train">Prototype Train</a>. This Railyard has a <a href="./Water%20Tower.md" class="wikilink" title="Water Tower">Water Tower</a> and <a href="./Oil%20Tank.md" class="wikilink" title="Oil Tank">Oil Tank</a> for refueling the train.</p>
<p>Heading further West will take the player to <a href="./Anna%20Island%20--%20Track%20Section%203.md" class="wikilink" title="Anna Island -- Track Section 3">Anna Island -- Track Section 3</a>. An Aurora gate and a bridge block access to the next island over, and must be opened during the <a href="./Aurora.md" class="wikilink" title="Aurora">Aurora</a>.<strong>Lua execution error in Module:Navbox function navbox</strong></p></td>
