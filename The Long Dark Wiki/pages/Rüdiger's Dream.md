**Rüdiger's Dream** is an <a href="./The%20Long%20Dark%20%E2%80%94%20Achievements.md" class="wikilink" title="achievement">achievement</a> in *<a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>*.

## Guide

This achievement is easiest to unlock when playing on <a href="./Pilgrim.md" class="wikilink" title="Pilgrim">Pilgrim</a>. The player must complete all 3 <a href="./Tales.md" class="wikilink" title="Tales">Tales</a> in a single <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> game:

- <a href="./Signal%20Void.md" class="wikilink" title="Signal Void">Signal Void</a>
- <a href="./Buried%20Echoes.md" class="wikilink" title="Buried Echoes">Buried Echoes</a>
- <a href="./Last%20Horizon.md" class="wikilink" title="Last Horizon">Last Horizon</a>

Completing <a href="./Sutherland%27s%20Tale.md" class="wikilink" title="Sutherland&#39;s Tale">Sutherland's Tale</a> is not needed to unlock this achievement.**Lua execution error in Module:Navbox function navbox**
