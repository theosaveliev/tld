**Security Chief's Log 32** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> as part of the <a href="./Buried%20Echoes.md" class="wikilink" title="Buried Echoes">Buried Echoes</a> <a href="./Tales.md" class="wikilink" title="Tale">Tale</a>. It is found in the storeroom on the right upon entering the entering the locked mountain section of the <a href="./Langston%20Mine.md" class="wikilink" title="Langston Mine">Langston Mine</a>.

## Transcript

<div style="margin: 0.8em 1.6em;font-style: italic;">

The following text is transcribed from **Security Chief's Log 32**

</div>

<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">

I can probably make it back to the surface before the weather turns again. Moving slowly now.

Recording as much as I can, the writing helps keep me here. Otherwise my mind wanders.

To the sea. To small ships and deep water. My mother’s voice.

</div>
