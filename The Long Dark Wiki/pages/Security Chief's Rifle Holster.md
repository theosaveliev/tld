<p>The <strong>Security Chief's Rifle Holster</strong> is a type of accessory in <em>The Long Dark</em>. It is part of the <em><a href="./Tales%20from%20the%20Far%20Territory.md" class="wikilink" title="Tales from the Far Territory">Tales from the Far Territory</a></em> DLC.</p>
<h2 id="Overview">Overview</h2>
<p>The Security Chief's Rifle Holster is a <a href="./Clothing.md" class="wikilink" title="Clothing">Clothing</a> item that when worn in either accessory slot, reduces the weight of an equipped <a href="./Hunting%20Rifle.md" class="wikilink" title="Hunting Rifle">Hunting Rifle</a>, or one of its variants, by 50%:</p>
<ul>
<li><a href="./Hunting%20Rifle.md" class="wikilink" title="Hunting Rifle">Hunting Rifle</a>
<ul>
<li>Unloaded 4.00 kg = (2.00kg)</li>
<li>Fully Loaded 4.20 kg = (2.10kg)</li>
</ul></li>
<li><a href="./Barb%27s%20Rifle.md" class="wikilink" title="Barb&#39;s Rifle">Barb's Rifle</a>
<ul>
<li>Unloaded 4.50 kg = (2.25kg)</li>
<li>Fully Loaded 4.70 kg = (2.35kg)</li>
</ul></li>
<li><a href="./Bunker%20Rifle.md" class="wikilink" title="Bunker Rifle">Bunker Rifle</a>
<ul>
<li>Unloaded 1.50 kg = (0.75kg)</li>
<li>Fully Loaded 1.70 kg = (0.85kg)</li>
</ul></li>
<li><a href="./Curator%27s%20Rifle.md" class="wikilink" title="Curator&#39;s Rifle">Curator's Rifle</a>
<ul>
<li>Unloaded 4.00 kg = (2.00kg)</li>
<li>Fully Loaded 4.20 kg = (2.10kg)</li>
</ul></li>
<li><a href="./Vaughn%27s%20Rifle.md" class="wikilink" title="Vaughn&#39;s Rifle">Vaughn's Rifle</a>
<ul>
<li>Unloaded 3.00 kg = (1.50kg)</li>
<li>Fully Loaded 3.20 kg = (1.60kg)</li>
</ul></li>
</ul>
<p>The holster provides no other bonuses, such as <a href="./Warmth.md" class="wikilink" title="Warmth">Warmth</a> or <a href="./Clothing.md#Windproof" class="wikilink" title="Windproofing">Windproofing</a>. Like other clothing, the holster is vulnerable to damage from <a href="./Struggle.md" class="wikilink" title="Struggle">Struggle</a> and <a href="./Weather.md" class="wikilink" title="blizzards">blizzards</a>, though it is sturdy and relatively easy to repair.</p>
<h2 id="Location">Location</h2>
<p>The holster is found in the kitchen of <a href="./Bunker%20Omega.md" class="wikilink" title="Bunker Omega">Bunker Omega</a>, having belonged to the Chief Security Officer overseeing the Rüdiger's Project. It is the ultimate prize for completing the <a href="./Tales.md" class="wikilink" title="Tale">Tale</a> <a href="./Signal%20Void.md" class="wikilink" title="Signal Void">Signal Void</a>.</p>
<p>Security Chief's Rifle Holster is not available on <a href="./Interloper.md" class="wikilink" title="Interloper">Interloper</a>.</p>
