**Shopping List** is a <a href="./Collectibles.md" class="wikilink" title="Collectibles">Collectibles</a> found in <a href="./Episode%205%20-%20The%20Light%20At%20The%20End%20Of%20All%20Things.md" class="wikilink" title="Episode 5">Episode 5</a> of the <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> story. It is found during the main mission <a href="./High%20Energy.md" class="wikilink" title="High Energy">High Energy</a>, inside the <a href="./Glove%20Box.md" class="wikilink" title="Glove Box">Glove Box</a> of the single <a href="./Truck.md" class="wikilink" title="Truck">Truck</a> parked outside the <a href="./Suzuki%20Radio%20Telescope.md" class="wikilink" title="Suzuki Radio Telescope">Suzuki Radio Telescope</a>.

The code 1859 is a reference to the [Carrington Event](https://en.wikipedia.org/wiki/Carrington_Event) that occurred in the same year, a reference to Atwood's work and her research leading up to the <a href="./First%20Flare.md" class="wikilink" title="First Flare">First Flare</a>.
