The **Time Capsule** is a playable archive released on September 20th 2019 to commemorate 5 years of development of *<a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>.* It was released for free by Hinterland, and allows users to play previous builds of the game as far back as the pre alpha builds. This functionality is currently only available to Steam users due to Steam's infrastructure allowing access to beta build archives of *The Long Dark*.

Keep in mind that all previous versions of the game are Unsupported, meaning that these are old builds that will not be receiving any new updates. Many forms of <a href="./Cut%20%E2%80%94%20Discontinued%20Content.md" class="wikilink" title="Cut/Discontinued Content">Cut/Discontinued Content</a> that have long since been removed exist within previous builds of the game, and have their own pages on this Wiki should you encounter them (example cut tools and mechanics/early Wintermute Predux missions).

It is still possible to earn <a href="./The%20Long%20Dark%20%E2%80%94%20Achievements.md" class="wikilink" title="Steam Achievements">Steam Achievements</a> when using older builds of the game, though some Wintermute achievements cannot be unlocked when playing a build that existed before certain Episodes were released. It is not possible to earn any cut <a href="./The%20Long%20Dark%20%E2%80%94%20Achievements.md#Game_History" class="wikilink" title="achievements">achievements</a> from the alpha version of the game.

The page for Hinterland's Time Capsule can be found here: <https://www.thelongdark.com/time-capsule/>

## Install Instructions

- 1\. Launch Steam.
- 2\. Go to your Library.
- 3\. Right click on The Long Dark in your Steam library and select Properties:
- 4\. This will open a menu. Now select the Betas tab:
- 5\. Here you will be able to input the Archive Build of your choice.
- 6\. Enter the code and click the Check Code button:
- 7\. Now select the branch from the drop down menu:
- 8\. This will update your installed version of the game to the branch.
- 9\. Once completed the branch name will appear next to the The Long Dark in your library list.
- 10\. To return to the most Current version, select "NONE" in the Beta drop down and the game will reinstall the most modern game files.
