The **Toxic Fog** is a feature included in the <a href="./Escape%20the%20Darkwalker.md" class="wikilink" title="Escape the Darkwalker">Escape the Darkwalker</a> mode of <a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>.

## Description

During Escape the Darkwalker, every <a href="./Region.md" class="wikilink" title="Region">Region</a> in the game is given a timer of a certain amount of minutes dependent on the size of the region, counted in real-time. Once the timer reaches zero, the entire region will fill with fog. As more time is spent in the region, visibility gradually decreases. While there are no blizzards, this can be a navigational hazard as the mode is set to night for the entire duration of the playthrough. There is no way to remove this fog once it appears. Before it descends, there is a timer on the map that is visible at all times. This can be seen in the 'map' section of the menus.

While there is no way to remove the fog, it is possible to delay its onset with a glyph from a can of <a href="./Spray%20Paint%20-%20Glyph.md" class="wikilink" title="Spray Paint - Glyph">Spray Paint - Glyph</a>. However, this glyph may only be drawn once per playthrough.

## Features

- When the fog descends, all <a href="./Wildlife.md" class="wikilink" title="Wildlife">Wildlife</a> will immediately be killed, both passive and aggressive. The Darkwalker will not be killed.
- When the fog descends, all <a href="./Food%20And%20Drink.md" class="wikilink" title="Food and Drink">Food and Drink</a> will immediately rot to 0% condition, and will provide 0 calories.
- When the fog descends, <a href="./Condition.md" class="wikilink" title="Condition">Condition</a> will deteriorate rapidly.
- If killed by the fog, the ending screen will state you have been killed by the Darkwalker.
- When the fog warning in the HUD reaches 2 minutes, it will show up as a red symbol and the effects of the fog immediately start causing harm to condition, wildlife and food.
