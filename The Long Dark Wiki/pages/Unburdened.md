<p><strong>Unburdened</strong> is a unique Benefit <a href="./Afflictions.md" class="wikilink" title="Affliction">Affliction</a> in <em><a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a></em> only encountered in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> when consuming certain <a href="./Cooking.md" class="wikilink" title="Cooking">Cooking</a> Recipes. It was added in the Part 3 update to the <a href="./Tales%20from%20the%20Far%20Territory.md" class="wikilink" title="Tales from the Far Territory">Tales from the Far Territory</a>.</p>

<tbody>

<p>Unburdened is acquired from consuming certain recipes that effects a survivor's <a href="./Encumbrance.md" class="wikilink" title="Encumbrance">Encumbrance</a> by temporarily increasing their maximum total Carry Weight by 3kg for 3 hours. This effect stacks with any other increases to Carry Weight (<a href="./Moose-Hide%20Satchel.md" class="wikilink" title="Moose-Hide Satchel">Moose-Hide Satchel</a>, <a href="./Technical%20Backpack.md" class="wikilink" title="Technical Backpack">Technical Backpack</a>, <a href="./Well%20Fed.md" class="wikilink" title="Well Fed">Well Fed</a>).</p>
<p>The following foods when consumed grant the Unburdened Affliction as a side effect:</p>
<ul>
<li><img src="../assets/Coastal_Fishcakes_icon.png" loading="lazy" width="29" height="29" alt="Coastal_Fishcakes_icon.png" /> <a href="./Coastal%20Fishcakes.md" class="wikilink" title="Coastal Fishcakes">Coastal Fishcakes</a></li>
<li><img src="../assets/Rabbit_Pie_icon.png" loading="lazy" width="29" height="29" alt="Rabbit_Pie_icon.png" /> <a href="./Rabbit%20Pie.md" class="wikilink" title="Rabbit Pie">Rabbit Pie</a></li>
<li><img src="../assets/Venison_Pie_icon.png" loading="lazy" width="29" height="29" alt="Venison_Pie_icon.png" /> <a href="./Venison%20Pie.md" class="wikilink" title="Venison Pie">Venison Pie</a></li>
<li><img src="../assets/Pemmican_Bar_icon.png" loading="lazy" width="29" height="29" alt="Pemmican_Bar_icon.png" /> <a href="./Pemmican%20Bar.md" class="wikilink" title="Pemmican Bar">Pemmican Bar</a></li>
<li><img src="../assets/Porter%27s_Soup_icon.png" loading="lazy" width="29" height="29" alt="Porter&#39;s_Soup_icon.png" /> <a href="./Porter%27s%20Soup.md" class="wikilink" title="Porter&#39;s Soup">Porter's Soup</a></li>
</ul>
<p>The effect of this Affliction does not stack, and each application will not override the previous Affliction. Partially eating the previously mentioned foods only adds a partial amount of Unburdened benefit duration.</p>
