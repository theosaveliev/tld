The **Urn** was a cut container found during the Predux version of <a href="./Episode%201%20-%20Do%20Not%20Go%20Gentle.md" class="wikilink" title="Episode 1: Do Not Go Gentle">Episode 1: Do Not Go Gentle</a>. It was found in the <a href="./Paradise%20Meadows%20Farm.md" class="wikilink" title="Paradise Meadows Farm">Paradise Meadows Farm</a> farmhouse bedroom, and contained <a href="./Bank%20Deposit%20Box%20Key%2015.md" class="wikilink" title="Bank Deposit Box Key 15">Bank Deposit Box Key 15</a>, needed to finish the mission <a href="./The%20Grey%20Mother%20%28Predux%29.md" class="wikilink" title="The Grey Mother (Predux)">The Grey Mother (Predux)</a>.

It has since been removed from the game after the V1.47 Wintermute Redux version of Episode 1 was released, but can still be experienced by downloading versions V1.15, V1.30, or V1.37 of Steam version of *<a href="./The%20Long%20Dark.md" class="wikilink" title="The Long Dark">The Long Dark</a>* by using the <a href="./Time%20Capsule.md" class="wikilink" title="Time Capsule">Time Capsule</a>.

It now considered <a href="./Cut%20%E2%80%94%20Discontinued%20Content.md" class="wikilink" title="Cut/Discontinued Content">Cut/Discontinued Content</a>. A spiritual successor to the Urn would appear years later in <a href="./Episode%203%20-%20Crossroads%20Elegy.md" class="wikilink" title="Episode 3: Crossroads Elegy">Episode 3: Crossroads Elegy</a> as the <a href="./Vase.md" class="wikilink" title="Vase">Vase</a>.
