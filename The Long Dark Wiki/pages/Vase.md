**Vase** is a unique storage container only found in <a href="./Episode%203%20-%20Crossroads%20Elegy.md" class="wikilink" title="Episode 3: Crossroads Elegy">Episode 3: Crossroads Elegy</a> as part of the <a href="./Trauma.md" class="wikilink" title="Trauma">Trauma</a> mission in the <a href="./Pleasant%20Valley%20Farmstead.md" class="wikilink" title="Pleasant Valley Farmstead">Pleasant Valley Farmstead</a>. It placed in the dining room on the table and can be searched after the phone call with <a href="./Molly.md" class="wikilink" title="Molly">Molly</a>.

It does not appear in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a>.

## Loot

The Vase only contains the <a href="./Basement%20Key.md" class="wikilink" title="Basement Key">Basement Key</a> as part of the opening mission.
