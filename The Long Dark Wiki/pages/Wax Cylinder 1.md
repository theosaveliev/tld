<p><strong>Wax Cylinder 1</strong> is a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> as part of the <a href="./Iron%20Road.md" class="wikilink" title="Iron Road">Iron Road</a> expansion. It is found in <a href="./Desolation%20Point.md" class="wikilink" title="Desolation Point">Desolation Point</a>, on the <a href="./Fulmar%20Autopilot%20Boat.md" class="wikilink" title="Fulmar Autopilot Boat">Fulmar Autopilot Boat</a> right next to the Play Me! note and <a href="./Wax%20Cylinder%20Player.md" class="wikilink" title="Wax Cylinder Player">Wax Cylinder Player</a>.</p>
<p>The Cylinder is narrated by Alice McLeod.</p>
<h2 id="Transcript">Transcript</h2>
<div style="margin: 0.8em 1.6em;font-style: italic;">
<p>The following text is transcribed from <strong>Wax Cylinder 1</strong></p>
</div>
<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">
<p>Whoever finds this message. Please, Do not turn away.</p>
<p>I know how strange this all must seem to you.</p>
<p>I found something. An island far from where you're standing. There's a deep mystery here. I've only just scratched the surface.</p>
<p>And I can't leave.</p>
<p>I've seen enough to know that solving it will help us all survive what's coming. If you've found this message and you want to live, you'll have to trust me.</p>
<p>You'll have to find me.</p>
<p>I'm leaving this message using the only recording technology that still seems to work, hoping against all hope that someone finds it before something happens to me.</p>
<p>This boat is equipped with a kind of auto-navigation I've managed to improvise. I have no idea if it'll work.</p>
<p>But if you found this recording, it must have brought the boat to you.</p>
<p>And if it brought the boat to you, it can bring you back to me.</p>
<p>Load up on supplies. Get the boiler going, and engage the throttle. With any luck, the navigation system should take over.</p>
<p>It'll follow a route I've set for it, to bring you here.</p>
<p>Theoretically, it should even let you travel back to Great Bear if you need to.</p>
<p>There's not much time, and what I have to share could change your world forever. So please, don't give up on me.</p>
<p>Please hurry.</p>
<p>Come find me, on Cauldron Island.</p>
</div>
