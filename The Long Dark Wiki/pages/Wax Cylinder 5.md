<p><strong>Wax Cylinder 5</strong> is a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> in <a href="./Survival%20Mode.md" class="wikilink" title="Survival Mode">Survival Mode</a> as part of the <a href="./Iron%20Road.md" class="wikilink" title="Iron Road">Iron Road</a> expansion. It is found in <a href="./Port%20Remnant.md" class="wikilink" title="Port Remnant">Port Remnant</a> inside the <a href="./Desecrated%20Church.md" class="wikilink" title="Desecrated Church">Desecrated Church</a>.</p>
<p>The Cylinder is narrated by Elsa.</p>
<h2 id="Transcript">Transcript</h2>
<div style="margin: 0.8em 1.6em;font-style: italic;">
<p>The following text is transcribed from <strong>Wax Cylinder 5</strong></p>
</div>
<div style="background: #2D3035; border: 1px solid #2D3035; border-radius: 0 0 120px 120px / 0 0 8px 8px; box-shadow: 0 5px 7px -7px rgb(0 0 0 / 40%); max-width: 90ch; overflow: hidden; padding: 2em; margin-bottom: 1em;">
<p>Erik? It has been months since I've been able to get any mail off the island.</p>
<p>This is Elsa.</p>
<p>I hope you can hear me.</p>
<p>I've managed to get my hands on one of these cylinder contraptions the chief engineer was always going on about.</p>
<p>I'm trying to leave some record, some memory, of what I have seen here on these islands.</p>
<p>I do it for the children. The innocents, who do not deserve to live through what is happening here.</p>
<p>Meanwhile, he's trying to destroy the truth.</p>
<p>I've heard that he's planning to break everything. Collecting all the records, then smashing or melting them down.</p>
<p>So nobody will ever know what he has started here.</p>
<p>But I'm small. Insignificant. Nobody notices me.</p>
<p>I will use that to my advantage.</p>
<p>I will gather all the records that I can, and hide them. So McLeod cannot ever find them.</p>
<p>Perhaps in the future, they will again be found.</p>
<p>And the truth can be known.</p>
<p>I love you, Erik. I will hide this cylinder if I can't find anyone to take it off the island.</p>
<p>But know that I think of you, always.</p>
</div>
