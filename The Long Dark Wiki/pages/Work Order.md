**Work Order** is a <a href="./Collectibles.md" class="wikilink" title="Collectible">Collectible</a> note found in <a href="./Episode%204%20-%20Fury%2C%20Then%20Silence.md" class="wikilink" title="Episode 4">Episode 4</a> of the <a href="./Wintermute.md" class="wikilink" title="Wintermute">Wintermute</a> story. It is found in the boiler room of the <a href="./Steam%20Tunnels.md" class="wikilink" title="Steam Tunnels">Steam Tunnels</a>, next to a <a href="./Bedroll.md" class="wikilink" title="Bedroll">Bedroll</a> and some supplies.
